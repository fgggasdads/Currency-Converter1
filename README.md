# 💱 Currency Converter — Конвертер валют

**Автор:** Никита Яшков
**Язык:** Python 3.x  
**Библиотеки:** tkinter (стандартная), requests, json (стандартная)  
**API:** exchangerate-api.com  
**Формат данных:** JSON (`history.json`)  
**Управление версиями:** Git / GitHub

---

## 📋 Описание приложения

Графическое приложение для конвертации валют. Позволяет:
- Выбирать валюту "из" и "в"
- Вводить сумму для конвертации
- Получать актуальный курс через внешний API
- Сохранять историю конвертаций в JSON
- Загружать историю при запуске
- Очищать историю

---

## 🔑 Как получить API-ключ

1. Перейдите на [exchangerate-api.com](https://app.exchangerate-api.com/sign-up)
2. Зарегистрируйтесь (бесплатный тариф — 1500 запросов/месяц)
3. Подтвердите email
4. Скопируйте ваш API-ключ на главной панели
5. Вставьте его в код в строке:
   ```python
   self.api_key = "ВАШ_API_КЛЮЧ"

---

🚀 Инструкция по запуску
Установите Python 3.x (если не установлен)

Установите библиотеку requests:

bash
pip install requests
Скачайте или склонируйте репозиторий:

bash
git clone https://github.com/ваш_логин/CurrencyConverter.git
Перейдите в папку проекта:

bash
cd CurrencyConverter
Вставьте ваш API-ключ в файл main.py

Запустите приложение:

bash
python main.py

## 🧪 Примеры тестов
Тип теста	Действие	Ожидаемый результат
Позитивный	100 USD → EUR	Вывод результата, сохранение в историю
Позитивный	Обновить курс	Курс обновляется, статус "Курс обновлён"
Негативный	Отрицательное число	Ошибка "Сумма должна быть положительным числом"
Негативный	Буквы вместо числа	Ошибка "Введите корректную сумму"
Негативный	Нет интернета	Сообщение "Нет соединения"
Граничный	Сумма 0.01	Работает корректно
Граничный	Очистка истории	Подтверждение, история очищается
